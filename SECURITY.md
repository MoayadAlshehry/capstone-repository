# Security reporting

This is an academic MVP supplied for the limited evaluation scope described in RIGHTS.md and the exact release permission record. No formal security certification, response-time guarantee or production suitability promise is made.

Please do not post credentials, private academic records, working exploit payloads or recovery information in a public issue. If GitHub private vulnerability reporting is enabled for this repository, use **Security → Report a vulnerability**. If that option is unavailable, open a public issue asking the maintainer for a confidential reporting channel, without sensitive details; wait for that channel before disclosing them. Do not assume a private reporting feature is enabled merely because this document exists.

Identify the affected immutable release, relevant source paths and a minimal synthetic reproduction. Test only an instance you own and have permission to assess. Do not probe the demonstration site, other users' installations or third-party model/mail services. Do not include session cookies or token values in reports.

The maintainer can triage a supported report and propose a separately versioned correction. Existing immutable tags/assets will not be silently replaced. Operators remain responsible for their own host, model/provider configuration, authorized data and backups.
