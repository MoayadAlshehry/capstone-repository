# Supported feature profiles

Normal installation provides the complete platform source with AI enabled after supported-model preflight and a fresh database. Add `--demo` on a blank owned target to load the original synthetic dataset. The public loader uses its own resumable journal and preserves completed user data. Mail defaults to private local capture and Mailpit, with the supported provider configuration available when authorized credentials and recipients are supplied.

`--ai-off` is an explicit choice for a profile without AI features. Missing models lead to setup instructions and an operator choice. See [MODEL_REQUIREMENTS.md](MODEL_REQUIREMENTS.md) for generation/embedding setup and [MAIL_CONFIGURATION.md](MAIL_CONFIGURATION.md) for mail profiles and verification. Model weights and private configuration are provisioned separately. All applicable dependency terms remain in effect.
