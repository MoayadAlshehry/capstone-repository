# PalmTrace: Verifiable Irrigation Decision Records

A moisture-triggered controller needs reproducible explanations for each water allocation, particularly when sensors fail or a daily budget is exhausted.

## Read in this order
1. report/research.pdf
2. methods/research.md
3. experiments/irrigation.py
4. results/validation.csv
5. design/architecture.md

## Reproducibility

Thirty deterministic synthetic cases; no field deployment or human study is claimed. All comparison outputs are reproducible with the attached Python source. Cover media is an AI-generated conceptual illustration.

## Scope limitations

Moisture and evaporation are synthetic. Water savings here concern the stated simulator only and cannot predict crop yield or farm economics.
