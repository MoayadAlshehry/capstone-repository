# AccessMap: Explainable Accessibility Route Graphs

The shortest path may include stairs or a narrow connection. A route engine should expose why edges are excluded and distinguish unknown accessibility from verified suitability.

## Read in this order
1. report/research.pdf
2. methods/research.md
3. experiments/routes.py
4. results/validation.csv
5. design/architecture.md

## Reproducibility

Thirty deterministic synthetic cases; no field deployment or human study is claimed. All comparison outputs are reproducible with the attached Python source. Cover media is an AI-generated conceptual illustration.

## Scope limitations

All geometry and accessibility annotations are fictional. There are no surveyed buildings, participant studies or medical suitability claims.
