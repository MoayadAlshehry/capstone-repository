# SecureArchive: Tamper-Evident Research Manifests

Research bundles must detect changed bytes, deleted paths and ambiguous filenames without interpreting uploaded code or trusting a client-supplied checksum.

## Read in this order
1. report/research.pdf
2. methods/research.md
3. experiments/integrity.py
4. results/validation.csv
5. design/architecture.md

## Reproducibility

Thirty deterministic synthetic cases; no field deployment or human study is claimed. All comparison outputs are reproducible with the attached Python source. Cover media is an AI-generated conceptual illustration.

## Scope limitations

Integrity is not authenticity or malware detection. The artifact does not execute uploads, issue trusted signatures or replace institutional retention policies.
