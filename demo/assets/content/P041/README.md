# TaskPebble: Lightweight Personal Research Planner

TaskPebble explores research planning in a bounded, inspectable graduation-project demonstrator. The work emphasizes traceable input assumptions and visible failure cases rather than production claims.

## Read in this order
1. report/research.pdf
2. methods/research.md
3. experiments/validation.py
4. results/validation.csv
5. design/architecture.md

## Reproducibility

Thirty deterministic synthetic cases; no field deployment or human study is claimed. All comparison outputs are reproducible with the attached Python source. Cover media is an AI-generated conceptual illustration.

## Scope limitations

This early proof of concept has no field deployment, institutional endorsement or human study. The attached review identifies limited coverage and remaining validation work.
