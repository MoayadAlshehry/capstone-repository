# GridWise: Solar Microgrid Dispatch Under Uncertainty

A small energy store must trade grid draw against battery wear while handling a bounded uncertain solar input. Dispatch decisions require an explicit feasible-energy ledger.

## Read in this order
1. report/research.pdf
2. methods/research.md
3. experiments/microgrid.py
4. results/validation.csv
5. design/architecture.md

## Reproducibility

Thirty deterministic synthetic cases; no field deployment or human study is claimed. All comparison outputs are reproducible with the attached Python source. Cover media is an AI-generated conceptual illustration.

## Scope limitations

The simplified battery and tariff model omits degradation chemistry, grid protection and real installation certification. No field cost saving is claimed.
